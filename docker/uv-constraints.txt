# Version caps for the image installs (`uv pip install -c`), so the packages
# prod ships have the same versions in the dev image that CI runs.
#
# The dev stage installs the test and benchmarking dependencies into the same
# environment as the runtime ones, and fails if that changes any runtime
# package. When a dev-only dependency forces a lower version of a runtime
# package, cap the runtime package here so base installs that version too.
# Delete a cap once the dependency that forces it lifts its own.

# the perf/eval lane has run them on 5.

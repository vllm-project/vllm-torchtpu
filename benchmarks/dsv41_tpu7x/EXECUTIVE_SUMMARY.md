## 2. Serving Modes Overview

* **Prefill-Only (`1 Node = 4 Chips`)**: Runs 4 independent per-chip `TP=2, EP=2` instances executing only the 20-layer Context Encoder (`VLLM_DSV41_CED=1`, `PURE_20L_PREFILL=1`, `output_len = 1`) to measure maximum prompt ingestion throughput across `32K–128K` context lengths without decode interference.
* **Decode-Only (`1 Node = 4 Chips`)**: Runs a single `DP=8, TP=1, EP=8` instance with 100K pre-populated KV context (`99.94%` prefix cache hit) and **DSpark $K=5$** block-diffusion speculative decoding (`--async-scheduling`) to measure steady-state token generation throughput and TPOT at `c=64`, `c=256`, and `c=512`.
* **1P1D Disaggregated (`2 Nodes = 1 Prefill Node + 1 Decode Node`)**: Couples a 20-layer `CED=1` Prefill node (`kv_producer`) and a 40-layer `CED=0` + **DSpark $K=5$** Decode node (`kv_consumer`) over DCN via **`TPURaidenConnector` Stage 3** (transferring 55 typed KV pools with 128-token SWA window trimming) for end-to-end prefill + decode serving.

## 6. Model Overview: DeepSeek-V4.1-Flash ([Technical Report](https://arxiv.org/pdf/2609.19969))

DeepSeek-V4.1-Flash ([paper](https://arxiv.org/pdf/2609.19969)) is a hybrid **40-layer Context-Encoder-Decoder (CED)** MoE language model ($d = 5120$) co-designed with a **3-layer DSpark block-diffusion speculative drafter** for high-throughput long-context serving:

* **Asymmetric 20L Encoder + 20L Decoder (CED)**:
  * **Context Encoder (`Layers 0–19`)**: Encodes prompt tokens using **15 Sliding-Window Attention (`SWA`, window $W=512$)** layers and **5 Sparse Multi-head Latent Attention (`MLA`)** layers (`Layers 1, 7, 13, 19` + `Layer 20` cross-boundary KV projection) equipped with compressed-token strided top-$k$ indexers (`cr=2` $T=512$ at layers 2/8/14; `cr=1` $T=1024$ at layer 20).
  * **Decoder (`Layers 20–39`)**: Attends to the Encoder's Layer-20 KV state via **3 Cross-Shared Attention (`CSA`)** layers (`Layers 20, 26, 32`, which reuse Layer 20's KV cache without recomputing $K/V$) interleaved with **17 `SWA` ($W=512$)** layers.
  * **Why CED Transforms Prefill & Disaggregation**: Under `VLLM_DSV41_CED=1`, prompt prefill only executes the 20-layer Context Encoder (`Layers 0–19` + Layer-20 KV projection), halving prefill FLOPs. For 1P1D disaggregation, only the 5 long-context MLA/CSA KV caches plus a **trimmed 128-token (`20`-page) SWA tail** (`55` typed KV pools total) are transferred over DCN, while the 20 decoder SWA layers reconstruct their window on the decode node from the 128-token tail.
* **MXFP4 (`W4A8`) Routed MoE & Engram Conditional Memory**:
  * Routed experts use **MXFP4 weights** (`FP4` E2M1 + `UE8M0` block-32 scales) with dynamic `FP8` activations (`MOE_FUSED_EP_KERNEL_IMPL=v2`) and replicated shared experts; Layers `1` and `21` integrate **Engram** $N$-gram hash lookup tables.
* **DSpark Block-Diffusion Speculative Decoding ($K=5$, `Layers 40–42`)**:
  * A 3-layer lightweight SWA ($W=512$) draft model conditioned on the mean of target entry-stream hidden states from Layers `(37, 38, 39)` proposes $K=5$ draft tokens (`block_size = 6`) in parallel per step, achieving natural mean acceptance length **$\tau = 4.14\text{--}4.81$** on 100K-context decode.
